# Signaler une vulnérabilité

Merci de ne pas publier une vulnérabilité non corrigée dans une issue ou une discussion publique.

Utilisez les **Security Advisories** privés de GitHub pour ce dépôt, si cette fonctionnalité est disponible. Sinon, contactez le propriétaire du dépôt par un canal privé avant toute publication publique.

Indiquez si possible les versions concernées, les étapes pour reproduire le problème et son impact. N'incluez pas de données personnelles ni de secrets réels dans le rapport.

Ce projet est éducatif et ne publie pas de délai de prise en charge garanti. Les versions corrigées seront indiquées dans le dépôt lorsqu'un correctif sera disponible.
